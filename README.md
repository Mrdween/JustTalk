Главная идея: "Цитадель"

Киллер-фича проекта — специализированная прослойка (Middleware), которую я назвал «Цитадель».
В отличие от классических серверов, где запрос сразу идет в обработку, здесь внедрен механизм активной защиты:
Перехват: Все запросы проходят через изолированный блок. 
Стресс-тест: Цитадель намеренно «ломает» и мутирует запросы, проверяя реакцию серверной логики. 
Валидация: Выявление нежелательных паттернов и блокировка запросов от модифицированных клиентов (защита от
реверс-инжиниринга API). Вердикт: Только проверенный запрос возвращается на основной сервер для выполнения.

Стек технологий:
Проект амбициозен и открыт для разных технологий. Я планирую использовать Backend: Rust (Axum, SQLx) — основной движок
и Цитадель. 
High-load: Elixir — для распределенной логики очередей. 
Database: PostgreSQL — надежное хранилище. 
Client: React / Python (для десктоп-клиентов).
